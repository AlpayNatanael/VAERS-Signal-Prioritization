Natanael Alpay | University of California, Irvine
Prepared 8 November 2026

START HERE
Open VAERS_Presentation.html in a browser to read the full presentation with
executed outputs. It works without starting Python. Mathematical equations
may need an internet connection for the HTML export's MathJax renderer.

Open VAERS_Presentation.ipynb in Jupyter or VS Code to inspect or rerun the
notebook. Figures and explanatory tables are already embedded in the saved
notebook. Download the complete ZIP if you want to rerun it: the standalone
notebook and HTML do not include the input data and Python modules.

REPRODUCE
Use Python 3.12.14, as in the verified source environment.
From this folder:
    python -m pip install -r requirements.txt
    python run_presentation.py

run_presentation.py starts a fresh Python kernel, executes every notebook
cell, saves its outputs, and rebuilds the HTML presentation. You can also
select Run All inside a notebook application using this Python environment.

If an environment blocks local kernel sockets, use:
    python run_presentation.py --in-process
This executes the same cells in order using IPython within a fresh Python
process and captures their text, tables, and figures. This mode was used for
the delivered notebook because this execution environment blocks sockets.
The execution report and notebook metadata record the mode used.

The notebook refits logistic regression and histogram gradient boosting in
all nine existing chronological evaluation windows. It starts from the
frozen processed panel in analysis/inputs; it does not repeat raw-report
ingestion. Seed 42 and the archived model settings are preserved.

STRUCTURE
VAERS_Presentation.ipynb : explanatory notebook with executed outputs
VAERS_Presentation.html  : readable presentation; code cells hidden
analysis/presentation.py : short notebook calls use these plotting helpers
analysis/source/         : unchanged corrected scientific pipeline
analysis/verify_*.py     : unchanged independent verification scripts
analysis/inputs/         : frozen processed inputs and reference results
analysis/results/        : regenerated predictions, metrics, and checks
figures/                 : presentation figures as PNG and vector PDF
tables/                  : small presentation tables as CSV
execution_report.json    : record of the most recent notebook execution
build_notebook.py        : reconstructs the notebook before execution
MANIFEST_SHA256.json     : hashes of the files in this presentation package

SOURCE AND SCOPE
The analysis folder was recovered from VAERS_Numerical_Verification_20261013.zip.
The source archive's 31 file checksums were verified before this run.
analysis/README.txt and analysis/FILE_SHA256.json document that original
archive. The latter is historical provenance, not a checksum list for the
new result files generated by this presentation. The notebook checks the
unchanged source/input hashes before each run. MANIFEST_SHA256.json records
the files in the new presentation package.

History begins in 2022. First observed crossings are not necessarily new
clinical associations. The target is a fixed statistical rule crossing.
Results describe ranking performance on already examined historical data;
they do not establish vaccine causality, clinical usefulness, or what data
were publicly available at each simulated forecast date.

The original project notebook and accepted poster PDF have not been edited.
For the Git repository structure, documentation, and automation, see README.md.
