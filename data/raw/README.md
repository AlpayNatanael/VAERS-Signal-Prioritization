# Optional raw inputs

For raw-data reconstruction, place these files here for each year 2022–2026:

- `YYYYVAERSDATA.csv`
- `YYYYVAERSVAX.csv`
- `YYYYVAERSSYMPTOMS.csv`

Use the expanded CSV format containing `ORDER`. These local files are excluded
from Git. They are unnecessary for rerunning the presentation notebook, which
uses the supplied aggregate panel.

See [data and provenance](../../docs/DATA.md) for snapshot hashes and commands.
